# Expected toy-dataset behavior

This toy dataset is intentionally tiny and artificial. It is only for checking installation, file format, command flow, and reader-friendly interpretation.

Expected qualitative pattern:

- `Fermented` has a stronger shared shift in several features, so it should usually route toward higher directional organization than `Fiber`.
- `Fiber` has smaller and less consistent shifts, so it should usually route toward weaker or mixed organization.
- No biological or clinical claim should be made from this dataset.
