# Route Examples

These examples define conservative routing patterns for David/Palleja-style trial runs and probe folders.

## David-Style Strong Perturbation

Use route: paired compositional workflow only when explicit subject-level baseline/post pairing is available.

Record:

- dataset role: magnitude or strong-perturbation implementation stress test
- endpoint rule
- sample overlap
- pairability decision
- pairing map path
- seed and permutation count
- output directory
- claim boundary

Interpretation boundary:

David-style runs may show large displacement without clear directional organization. Treat that as implementation behavior under a strong perturbation route, not as biological validation or a clinical conclusion.

## Palleja Antibiotic-Recovery Routing

Use route: paired compositional workflow only when D0-to-later endpoint pairing is explicit and subject IDs are unambiguous.

Record:

- endpoint labels and timepoints
- subject ID field
- sample ID field
- sample overlap
- explicit pairing map path
- skipped transitions and reasons
- seed and permutation count
- claim boundary

Interpretation boundary:

Palleja-style runs may show early disruption organization and reversal-like recovery in species-space geometry. Treat that as an antibiotic-recovery implementation stress test, not as treatment-effect evidence.

## Palleja Pathway-Space Contrast

Use route: biological-context implementation contrast when pathway-space summaries are available alongside species-space summaries.

Record:

- pathway feature table source and format
- species/pathway sample overlap
- endpoint rules
- pathway pairability
- species-vs-pathway comparison table
- seed and permutation count
- claim boundary

Interpretation boundary:

Pathway-space Palleja results are biological-context implementation contrasts. Do not call them pathway activity, mechanism, pathway mechanism, or biological validation.

## Probe Folder

Use route: cleanup-needed/not-ready unless the folder includes explicit inputs and routing metadata.

Acceptable probe use:

- input-readiness check
- output-shape check
- logging check
- refusal-path example

Conservative refusal:

If pairing is ambiguous, refuse paired response geometry. Ask for a pairing map with subject ID, baseline sample ID, post sample ID, endpoint labels, and the endpoint rule.
