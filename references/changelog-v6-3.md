# Changelog v6.3

Added release-readiness support for community adoption.

## Added

- Five-minute toy vignette in `tutorials/five-minute-toy-vignette.md`.
- Minimal artificial toy dataset in `examples/toy_dataset/`.
- Input data structure guide in `references/input-data-structure.md`.
- Conda-style environment file in `env/environment.yml`.
- Minimal Docker starting point in `env/Dockerfile`.
- Session information template in `env/session-info-template.md`.

## Boundaries

The toy dataset is only for workflow demonstration. It must not be described as biological validation, software validation, benchmark evidence, or clinical decision support.
